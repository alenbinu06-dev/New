- Due **11 September 2026, 23:59** — Word format, via Canvas.
- Worth **25%** of the unit: group report **15%**, individual reflective report **10%**.
- Group report **max 12 pages A4**; individual report **2–3 pages**.
- Groups of **4–5**, finalised by **week 2**.
- Project window: awarded **end March 2027**, complete by **31 May 2029**.
- **Sketches are mandatory** — a submission without adequate sketches is rejected.
- **GenAI tools are prohibited for this assessment** (see [`AGENTS.md`](AGENTS.md)).
